# 网站改版:浅色玻璃宋体 → 绝区零风格

## Context

zzzvoid 单页站目前是「浅色纸面 + 液态玻璃 + 思源宋体」的安静 Apple 风(主题集中在 `apps/website/src/styles.css` 的 5 个 token + `glass` 工具类)。用户希望整站改成**绝区零 (ZZZ) 风格**——zzzvoid 这个名字本就来自 ZZZ,与项目名呼应。已确认三个取向:

1. **黑底 + ZZZ 黄**(`#ffe600` 附近)+ 白字 + 噪点质感
2. **换思源黑体**(Noto Sans SC Variable),标题 900 黑度
3. **轻度文案风味**:加英文眉标/编号/「新艾利都」等装饰词,正文事实一律不动(不编造)

ZZZ 设计语言要点:黑/白/黄、斜切角(chamfer)卡片、贴纸式标签、半调网点/电视噪点、警示条纹、粗黑无衬线 + 大字距英文小标、干脆利落的动效、跑马灯 ticker。

## 改动清单

### 1. `apps/website/package.json` — 字体依赖

- 移除 `@fontsource-variable/noto-serif-sc`,换成 `@fontsource-variable/noto-sans-sc`
- 根目录跑 `vp install`

### 2. `apps/website/src/styles.css` — 全量主题重写(核心)

- **Token 换值**:`--color-paper→--color-void`(#0c0c0d 页面底)、新增 `--color-panel`(#17171a 卡片底)、`--color-ink`→白 #f4f4f5、`--color-dim`→#8b8b93、`--color-line`→#2a2a2e、`--color-accent`→ZZZ 黄 #ffe600。`color-scheme: dark`
- **字体**:`@import "@fontsource-variable/noto-sans-sc"`,`--font-sans` 为正文字体,`--font-mono` 保留给标签/数据
- **删除 `glass`**;新增 ZZZ 工具类:
  - `cut-corner`(clip-path 斜切角,卡片 14px / 按钮 8px 两档)
  - `panel`(bg-panel 基础面)
  - `halftone`(radial-gradient 网点)、`hazard`(repeating-linear-gradient 警示斜纹)
  - `.label`(黄色贴纸小标:bg-accent text-void + skew)
- **body::before** 玻璃晕染 → SVG feTurbulence 噪点层(低透明度,固定)
- **动效**:`settle` 去掉模糊改干脆位移;新增 `ticker` 跑马灯 keyframes(线性无限循环,reduced-motion 下停);`hover-scale` 换成卡片「硬阴影位移」悬停(translate + drop-shadow 硬黄影,兼容 clip-path);保留 hover-lift/press/arrow-nudge
- 滚动条换深色、`::selection` 黄底黑字、focus ring 黄

### 3. `apps/website/src/routes/__root.tsx`

- `theme-color` → `#0c0c0d`
- favicon data-URI 重绘:黑方块 + 黄色斜切杠(替换白底蓝点)

### 4. 组件改造(全部在 `src/components/`)

- **section.tsx**:加 `index`/`en` 两个可选 prop → 标题区变成「mono 黄色眉标 `01 / WORK ARCHIVE` + 黑体大标题」
- **site-header.tsx**:玻璃胶囊 → 顶部细黄条 + 深色不透明条(`bg-void/90 backdrop-blur` + `border-b border-line`),logo 变黄色方块 `bg-accent text-void`(微 skew),导航 hover `bg-accent text-void`
- **hero.tsx**:加眉标 `◼ 新艾利都 · NEW ERIDU — 独立软件工作室`;H1 改 font-black,「耐用」二字用黄色块高亮;主按钮 `bg-accent text-void` 斜切角、副按钮白描边斜切角;加半调网点装饰块;hero 底部加 **ticker 跑马灯**(内容重复两份实现无缝循环)
- **work-section.tsx**:玻璃圆角卡 → `panel + cut-corner`,标签变黄色贴纸 + mono 年份,悬停 = 上移 + 黄色 drop-shadow 硬影;删掉 `cardHover` 玻璃内高光阴影串
- **services-section.tsx**:dt 加 mono 黄色编号(01. 02. …)+ font-bold
- **principles-section.tsx**:加黄色描边空心大数字(01/02/03,`-webkit-text-stroke`)与黑体条目名并排
- **contact-section.tsx**:CTA 改 font-black,链接 mono 黄 hover
- **site-footer.tsx**:顶部边框换 hazard 警示条纹
- **arrows.tsx**:strokeWidth 1.5→2.5、圆头改方头(ZZZ 更硬朗的图标感)

### 5. 文案(轻度风味,不碰事实)

- 英文眉标在各组件内:`01 / WORK ARCHIVE`、`02 / SERVICES`、`03 / PROTOCOL`、`04 / SIGNAL`;hero 眉标含「新艾利都 · NEW ERIDU」;ticker 文案内联在 hero
- `data/site.ts` **不改动**(项目/服务/方法描述全部保持真实原文)

### 6. `apps/website/README.md`

- 同步更新其中对主题/styles.css 的描述(若提及宋体/玻璃)

## 验证

1. 根目录 `vp install`
2. `cd apps/website && pnpm dev`(端口 3000),用 agent-browser 截图桌面(1440)+ 移动(390)宽度,逐项核对:黑底黄 accent、斜切角卡片、贴纸标签、ticker 动画、无 glass/宋体残留;对照记忆中的教训用 evaluate 量尺寸而非依赖截图
3. `vp check`(格式/lint/类型)与 `vp test` 按 AGENTS.md 检查单执行
4. `vp build` 确认产物正常
